# Updates

Current version: 1.7.7. Download the [latest public Windows release](https://github.com/MazeXONE/GeminiBridgePro-Releases/releases/latest). Open Settings > Updates to see your installed version and check immediately. Automatic checks run at startup and daily. Download and installation require your actions. Save work, confirm, then choose Install & restart; active jobs block installation. Account/settings storage is kept.

Users of 1.7.4/1.7.5 run the 1.7.7 installer once over the existing installation, under the same Windows account and location. No uninstall is needed. The older builds do not contain this public feed. Portable users extract a new complete ZIP instead.

[Public version metadata](https://github.com/MazeXONE/GeminiBridgePro-Releases/releases/latest/download/latest.json) needs no GitHub login. Official updater artifacts use version-bound signatures; these are separate from Windows Authenticode publisher signing.

Source remains private. Authorized maintainers can read [signed build and publication instructions](https://github.com/MazeXONE/GeminiBridgePro/blob/main/docs/UPDATES.md).
