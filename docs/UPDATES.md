# Updates

Current version: 1.8.5. Download the [latest public Windows release](https://github.com/MazeXONE/GeminiBridgePro-Releases/releases/latest). Open Settings > Updates to see your installed version and check immediately. Automatic checks run at startup and daily. Select Download & install (or Download update followed by Install & restart) to update directly inside the app; active jobs block installation, and account/settings storage is kept.

Starting in 1.8.5, both Windows Installer and Portable editions support signed in-app updates. Users of 1.7.4/1.7.5 or earlier portable builds run the 1.8.5 installer or extract the 1.8.5 portable ZIP once to enter the current update channel.

[Public version metadata](https://github.com/MazeXONE/GeminiBridgePro-Releases/releases/latest/download/latest.json) needs no GitHub login. Official updater artifacts use version-bound signatures; these are separate from Windows Authenticode publisher signing.

Source remains private. Authorized maintainers can read [signed build and publication instructions](https://github.com/MazeXONE/GeminiBridgePro/blob/main/docs/UPDATES.md).
