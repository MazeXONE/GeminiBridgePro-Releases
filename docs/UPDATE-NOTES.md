Gemini Bridge Pro 1.8.5

Upgrades the pinned Magpie backend to **v0.18.0** with official **`AIStudio2API v0.3.15`+** & **`Gemini Web v4.31.0-magpie.2`** support (fixing Gemini 4 multi-turn tool `DELTA = +0` stalls across `argon`, `carbon`, `hydrogen`, and `neon`), introduces **Direct Magpie Mode (`127.0.0.1:2048`)** as the lightweight local default without requiring 9Router, adds a native **Claude Code (Anthropic)** client guide, defaults Parallel pool capacity to **Fill first** (`max_account_switches: 25`), and automatically disables **RTK** tool-output truncation when connecting 9Router.

- **Magpie `v0.18.0` & Official `AIStudio2API v0.3.15`+ (`Update backends`)**: Upgrades the verified Magpie commit to `v0.18.0` (`873194a34fad`), installing official `AIStudio2API v0.3.15`+ (fixing multi-turn tool-output `DELTA = +0` freezes on `gemini-4-argon`, `carbon`, `hydrogen`, and `neon`) and `Gemini Web v4.31.0-magpie.2`. Existing users can upgrade atomically via **Update backends** (`Guided setup → Backends`, `Gemini accounts → AI Studio`, or `gemini-bridge update-backends`) without losing any Google account sessions.
- **Direct Magpie Mode (`Direct (Magpie)` vs `Via 9Router`)**: Local coding clients now connect straight to AI Studio (`http://127.0.0.1:2048/v1` and `:2048`) in a single hop—saving hundreds of MB of RAM and bypassing intermediary proxy overhead. Switch anytime to **Via 9Router** when you need multiple separate client keys, Caddy public RDP HTTPS, or Gemini Web fallback.
- **Claude Code Native Anthropic Guide (`Other apps → Claude Code`)**: Generates ready-to-merge `~/.claude/settings.json` configuration (`ANTHROPIC_BASE_URL=http://127.0.0.1:2048`) with one-click AI Studio key copying.
- **Direct T3 Code, Codex CLI, Zed & Chatbox**: Generates unprefixed model configurations (`gemini-4-argon`, `magpie-studio`, `GEMINI_BRIDGE_API_KEY`) directly against Magpie `:2048` across all eight interface languages.
- **`Fill first` Parallel Strategy & Multi-Account Failover (`Tasks & parallel`)**: Parallel mode defaults to `fill-first` (with an explicit `Fill first` / `Round robin` selector) and automatically raises `max_account_switches` to `25` on `v0.3.15+`, keeping coding threads pinned to warm accounts for ~90% AI Studio cache hit rates while seamlessly skipping 403/cooldown accounts across large pools.
- **Automatic 9Router RTK Guard**: Connecting 9Router (`Connect automatically`, `Responses route`, or Caddy public proxy) automatically sets `rtkEnabled: false` so tool outputs in T3 Code and Codex are never truncated.
